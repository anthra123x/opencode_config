Display access links to the local OpenCode Swarm Web Cockpit & GetBrain Knowledge Graph:
- **Dashboard URL**: `http://localhost:4040`
- **GetBrain Graph**: `http://localhost:4040/#brain`

If the server is not yet running, inform the user they can launch it at any time with `ecc web --open` or `ecc web` from their terminal.
